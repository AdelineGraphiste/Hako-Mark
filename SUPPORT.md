
# Assistance Hako Mark / Hako Mark Support

## 🇫🇷 Français

Hako Mark est un logiciel Windows gratuit permettant d'annoter directement son écran.

### Télécharger le logiciel

[Télécharger Hako Mark pour Windows](https://github.com/AdelineGraphiste/Hako-Mark/releases/latest)

### Un problème technique ?

1. Consulte l'aide fournie avec le logiciel.
2. Vérifie que tu utilises la dernière version.
3. Si le problème persiste, utilise la rubrique [Signaler un problème](https://github.com/AdelineGraphiste/Hako-Mark/issues/new/choose).

Merci de préciser ta version de Windows et de décrire le problème rencontré.

Les signalements sont étudiés selon mes disponibilités. Aucune assistance individuelle ni correction systématique n'est garantie.

## 🇬🇧 English

Hako Mark is a free Windows application for annotating your screen.

### Download

[Download Hako Mark for Windows](https://github.com/AdelineGraphiste/Hako-Mark/releases/latest)

### Technical issue?

1. Check the help included with the software.
2. Make sure you're using the latest version.
3. If the problem persists, [report a bug](https://github.com/AdelineGraphiste/Hako-Mark/issues/new/choose).

Please include your Windows version and a description of the issue.

Bug reports are reviewed as time permits. Individual support and fixes are not guaranteed.
